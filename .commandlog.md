# Initializing Repo
`git clone https://github.com/lookitsmidge/bean-opt`

# Create Monorepo
`npx create-nx-workspace@latest`
```text
where?: bean-opt
starter: nrwl/angular-template
NxCloud: never
Usage: No
```

# Spring Cleaning of the NX Templates
`rm -rf apps/*`
`rm -rf libs/*`

`npx nx g @nx/angular:app apps/bean-opt-web --routing=true --style=scss --standalone=true`
```text
bunder: esbuild
SSR: false
```

# Installing Dependancies

- **Angular Material**: `npm install @angular/material @angular/cdk`, `px nx g @angular/material:ng-add --project=bean-opt-web`
- **Tailwind CSS**: `npm install tailwindcss @tailwindcss/postcss postcss`, 
- **SupabaseJS**: `npm install @supabase/supabase-js`

# Create Library (Core UI)

`npx nx g @nx/angular:library --name=core-ui --directory=libs/core/ui`

## Create Components inside the Core Ui Library

`npx nx g @nx/angular:component libs/core/ui/lib-shell/src/lib/shell --prefix=lib --changeDetection=OnPush`

## Testing

- **Running Vitest**: `npx vitest run`

## Supabase

- **Initialize**: `npx supabase init` 
- **Start**: `npx supabase start`
- **Create Migration**: `npx supabase migration new migration_name_here`
- **Reset local Db**: `npx supabase db reset`
