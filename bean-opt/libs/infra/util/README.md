# libs/infra/util

Low-level infrastructure utilities and service providers.

## Functionality
Provides the core service wrappers for third-party SDKs (Supabase, Firebase) and manages global application configuration tokens.

## Exports
- **Services**: `SupabaseService`, `FirebaseService`
- **Tokens**: `APP_CONFIG`
- **Data**: `database.types` (Auto-generated by Supabase CLI)
- **Models**: `NavigationModel`

## Technical Nuances
- **Supabase Wrapper**: The `SupabaseService` is the single source of truth for the `@supabase/supabase-js` client instance.
- **Type Safety**: Re-exports `database.types` to provide schema-aware typing for all data-access libraries.
- **Legacy Support**: Maintains the `FirebaseService` during the transition to Supabase.
